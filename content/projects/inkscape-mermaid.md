## Overview

**Mermaid Ink** brings [Mermaid.js](https://mermaid.js.org) diagram syntax directly into Inkscape. Write a flowchart, sequence diagram, Gantt chart, or entity-relationship diagram in Mermaid's plain-text syntax and render it as fully editable SVG — no browser, no external service.

## Supported diagram types

- Flowcharts (`graph TD`, `graph LR`)
- Sequence diagrams
- Gantt charts
- Entity-relationship diagrams
- Class diagrams
- State diagrams

## Installation

```bash
git clone https://github.com/YouvenZ/mermaid_ink
```

Requires the [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli) (`npm install -g @mermaid-js/mermaid-cli`).
